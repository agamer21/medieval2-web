# Dependencies and research provenance

The default playable battle uses original procedural geometry, canvas-drawn labels/ground and synthesized Web Audio tones. No original game models, textures, animations, audio or decompiled code are shipped for that battle. Its simulation rules are new code. The native asset viewer is preserved separately at `lab.html`.

- Three.js 0.187.0, from the official npm `three` package. Local `three.module.js`, `three.core.js` and `OrbitControls.js` are used. Three.js is MIT licensed; its license is included at `vendor/three/LICENSE`.
- lzo1x 1.0.1, from the official npm package associated with [mbtech-nl/lzo1x](https://github.com/mbtech-nl/lzo1x). Its pure-JavaScript MIT-licensed decoder is used for original archive blocks. The package's license is included at `vendor/lzo1x/LICENSE`.
- Original game models, textures, model database, animation packs and the shipped unpacker belong to their respective rights holders. They are read from the user's installation and kept outside this code package.
- Format research consulted the public `m2formats` documentation/source in [WK-313/Medieval-2-Blender-Toolkit](https://github.com/WK-313/Medieval-2-Blender-Toolkit/tree/7ac1c611bbf38a97686f44c119176af163efcff8/m2formats), pinned at `7ac1c611bbf38a97686f44c119176af163efcff8`. Its provenance document does not assert a standalone license grant. The downloaded reference sources remain private in `work/medieval2/references`; they have not been vendored into this package. The JavaScript readers and Python preparation tools here are separate implementations, validated against actual installed files.
- The [M2TWEOP project](https://github.com/EOP-Labs/M2TWEOP-library) is an extension of the original executable, not a replacement engine. It was investigated, not included.
- Archive-layout research also consulted the public `main/unittransfer/gamepack.py` format description in [ProJ-Yeet/Medieval2-GUI-Toolkit](https://github.com/ProJ-Yeet/Medieval2-GUI-Toolkit). No unlicensed reference source was copied into the deliverable. The separate browser PACK/index reader is validated against the official extractor; LZO decompression uses the MIT library listed above.
- [Boxedwine](https://github.com/danoon2/Boxedwine) is an optional compatibility research lead, not a dependency of this asset viewer. Its downloaded web release remains in the private work folder. It has not been added to the deliverable or used to run the original game.
